# ⚙️ Procurement and Inventory Module
A simple Java-based application designed to manage procurement and inventory processes within a clothing retail business. The system is built using **Java**, **Java Swing** for the graphical user interface, and **MySQL** for database management.

# 🚀 Getting Started
1. Start **XAMPP MySQL**.
2. Ensure database exists.
3. Check Java DB connection.
4. Run `Main.java`.

# 🔐 Hashed Password
👉 To generate the hashed password, open a phpMyAdmin and run:
* `INSERT INTO users (username, password)`
* `VALUES ('your_username_here', SHA2('your_password_here', 256));`
